# Zero Waste Cafe

A simple static restaurant website for Zero Waste Cafe, a concept cafe focused on thoughtful food, less waste, and a clean browsing experience.

## Live Link

Add live site link here: ['https://udarasadaruwan.github.io/zero-waste-cafe/']

## Project Files

- `index.html` - main page structure and content
- `styles.css` - layout, colors, typography, and responsive styles
- `app.js` - menu rendering and interactive behavior
- `assets/` - images used by the site

## How to View

Open `index.html` directly in a browser.

No build step or server is required.

## Editing

- Update page content in `index.html`.
- Update menu items in `app.js`.
- Update the visual design in `styles.css`.
- Add new images to `assets/` and reference them from the HTML or CSS.
